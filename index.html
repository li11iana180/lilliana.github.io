This paragraph is placed underneath the title, the things around this are called tags they tell HTML what the content within it is. There is always an opening tag <> and a closing tag with </>. You can think of tags as different types of containers.

The first <!DOCTYPE html> tag tells the brower to use the most up to date HTML version. The second tag, <html>, tells the browser everything within the tag belongs in the html. The <head> tag is a container for metadata for the browser to read, it tells the browser information such as, the tab bar title, other files it should reference etc. The <body> tag tells html that this is where the content of html page will be stored.
